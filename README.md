### 🔍 Unveil — Deepfake Detection Platform

An AI-powered application that detects whether an image is **REAL or FAKE**.

**What makes it interesting?**

* 🧠 EfficientNet-B0 deep learning model
* 🎯 ~98.5% test accuracy
* 🔥 Grad-CAM visual explanations
* ⚡ FastAPI inference backend
* ⚛️ React frontend

> Not just **"Is it fake?"** — but also **"Why does the model think so?"**
